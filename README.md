# DSC Document Tool

정격하중표(Rated Load Chart) 문서를 만드는 브라우저 기반 도구입니다. GitHub Pages에서 동작하는 정적 웹앱입니다.

- **이 저장소에는 프로그램 코드와 가상의 예시 데이터만 들어 있습니다.**
- 실제 기종 데이터, 개정 이력, 발행 문서는 사용자의 Google Drive에만 저장됩니다.

## 주요 기능 (개발 예정)

1. 기종 초기 설정 → 입력 양식 자동 생성
2. 정격하중 입력 (엑셀 붙여넣기 지원) 및 자동 검증
3. 개정(Rev) 단위 버전 관리
4. PDF 문서 생성 · 보관 · 배포 이력 관리
