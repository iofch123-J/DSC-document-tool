# 웹 등록 안내 (GitHub Pages + 구글 시트)

도구 화면은 GitHub Pages에 올리고, 데이터는 관리자 구글 계정에 둡니다.

| 무엇 | 어디에 | 누가 고치나 |
|---|---|---|
| 제품 분류 (No. · 분류 · 제품명 · Sub Winch · Sub Boom) | 구글 시트 '개발 DATABASE' | 관리자가 시트에서 직접 |
| 사용자 명단 (사번 · 이름 · 관리자 권한) | 같은 시트의 '사용자' 탭 | 관리자가 시트에서 직접 |
| 이력 (진입 · 진입 실패 · 종료 · 조회 · PDF 생성) | 같은 시트의 '이력' 탭 | 자동 기록 |
| 정격하중 데이터 · 회사 로고 | 관리자 구글 드라이브의 'DY Rated Load 데이터' 폴더 | 도구의 관리자 화면 |

사번·초성 확인은 구글 쪽 서버(Apps Script)에서 하므로 사용자 명단은 브라우저로 나가지 않습니다. 사용자는 구글 계정이 없어도 됩니다.

---

## 1. 개발 DATABASE를 구글 시트로

1. 구글 드라이브에 `1) 개발 DATABASE.xlsx`를 올립니다.
2. 파일을 열고 **파일 → Google Sheets로 저장**을 누릅니다. 새로 생긴 구글 시트를 앞으로 사용합니다.
3. 확인할 것
   - 제품 분류 표: 어느 탭이든 머리글 행에 `제품명` · `Sub Winch` · `Sub Boom`(선택: `분류`, `No.`)이 있으면 됩니다. 위쪽의 메모 영역은 그대로 둬도 됩니다.
   - `사용자` 탭: 머리글 `사번` · `이름` · `관리자 권한`. 관리자는 `관리자 권한` 칸에 `O`.
   - 관리자가 **한 명 이상** 있어야 관리자 화면에 들어갈 수 있습니다.
4. 시트 공유는 **제한됨**(본인만)으로 둡니다. 다른 사람과 공유할 필요가 없습니다.

## 2. Apps Script 붙이기

1. 구글 시트에서 **확장 프로그램 → Apps Script**.
2. 왼쪽 `Code.gs`의 내용을 모두 지우고, 저장소의 [`gas/Code.gs`](../gas/Code.gs) 내용을 통째로 붙여 넣은 뒤 저장(💾).
3. 위쪽 함수 선택에서 **`setup`**을 고르고 **실행**.
   - 처음 실행하면 권한 승인을 묻습니다: 계정 선택 → "Google에서 확인하지 않은 앱" 화면에서 **고급 → (프로젝트 이름)(으)로 이동** → 허용.
     (내가 만든 스크립트가 내 시트·드라이브를 쓰도록 허락하는 것입니다.)
   - 실행 로그에 `준비 완료 — 사용자 N명 (관리자 N명), 데이터 폴더: …`가 나오면 성공입니다.
   - 시트에 `이력` 탭이, 드라이브에 `DY Rated Load 데이터` 폴더가 생깁니다.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**.
2. 유형 선택(⚙) → **웹 앱**.
3. 설정
   - 설명: `DY Rated Load`
   - 다음 사용자 인증정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 이 URL을 알려 주면 `app/config.js`의 `API_URL`에 넣어 올립니다.

> '모든 사용자'여도 사번 + 이름 초성이 맞아야 데이터를 받을 수 있고, 5번 틀리면 그 사번은 15분 동안 잠깁니다.

## 4. GitHub Pages 켜기

1. GitHub 저장소 → **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main** / **(root)** → **Save**.
3. 1~2분 뒤 `https://iofch123-j.github.io/DSC-document-tool/` 에서 열립니다.
4. 짧은 주소: **`tinyurl.com/dscdoc`** → 위 주소로 넘어갑니다 (TinyURL 무료 별칭).

## 5. 처음 한 번

1. 웹 주소로 들어가 관리자 사번 + 이름 초성으로 들어갑니다.
2. **관리자 → 엑셀 가져오기**로 기종별 정격하중표 엑셀을 올립니다 → 드라이브에 저장되어 모든 사용자가 봅니다.
   (이 PC 브라우저에 있던 데이터는 자동으로 옮겨지지 않습니다. 엑셀이나 '백업 저장' JSON으로 다시 올리면 됩니다.)
3. **관리자 → 회사 로고 (CI)** 에 CI 이미지를 등록합니다.

## 운영

- **제품·사용자 변경**: 구글 시트에서 고치면 됩니다. 사용자 명단은 1분 안에, 제품 분류는 도구를 새로고침하면 반영됩니다.
  명단에서 빠진 사람은 다음 요청부터 들어올 수 없습니다.
- **이력**: 시트의 `이력` 탭, 또는 도구의 관리자 → 보안관리 → 이력(CSV 내려받기).
- **Apps Script를 고친 뒤**: 배포 → **배포 관리** → 연필(편집) → 버전: **새 버전** → 배포. URL은 그대로입니다.
- **데이터 백업**: 드라이브 폴더의 `models.json`은 드라이브가 버전 기록을 남깁니다(파일 우클릭 → 버전 관리).
- **로컬 모드**: `app/config.js`의 `API_URL`을 비우면 예전처럼 이 브라우저 안에만 저장하는 방식으로 돌아갑니다.

## 개발용: 구글 없이 시험하기

`tools/gas-mock.mjs`는 `gas/Code.gs`를 그대로 Node에서 돌리는 흉내 서버입니다(가짜 사용자 2명, 메모리에만 저장).

```bash
node tools/gas-mock.mjs --port 8770 --xlsx "<개발 DATABASE.xlsx 경로>"
```

브라우저 콘솔에서 `localStorage.setItem('rlc-api', 'http://127.0.0.1:8770/')` 후 새로고침하면 웹 모드로 동작합니다
(되돌리기: `localStorage.removeItem('rlc-api')`). 가짜 사용자: `12345HA` 홍길동(관리자, ㅎㄱㄷ), `23456HA` 이몽룡(ㅇㅁㄹ).
